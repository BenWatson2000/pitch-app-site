# Pitch

**A wild-camping spot logger for iPhone.** The whole of Great Britain's
contours, built into the app. Drop a pin where you are standing, get an
Ordnance Survey grid reference, and save it with a note and a photograph.

Every bit of it works in airplane mode. There is no account, no server and
nothing to sign up for.

### Things worth knowing before you write

**"My spots have disappeared."** They live on your phone and nowhere else,
which is the whole promise — but it also means deleting the app deletes them.
If you still have the app, check Spots; if a file has gone wrong, Pitch moves
it aside rather than deleting it and says so on the Spots screen. Export from
Settings gives you a copy you can keep.

**"The map is blank."** The contour map is built in and needs no signal. If it
is blank, the aerial photography layer is probably switched on without a
connection — turn it off from the map's controls and the contours come back.

**"It says it cannot save."** Pitch refuses to write over a file made by a
*newer* version of the app, because it cannot faithfully round-trip something
it does not understand. Updating the app fixes it. Nothing is lost in the
meantime.

**"The grid reference is not as precise as I expected."** That is deliberate.
Pitch never quotes a finer square than the GPS fix and the coordinate
transform honestly support. A reference with its precision beside it is a
reading; one without is a claim.
